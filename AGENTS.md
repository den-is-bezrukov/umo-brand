# UMO

React, Vite, Tailwind CSS v4 и TypeScript. Печатные файлы создаются в браузере.

Перед изменениями прочитайте профильные файлы в `docs/`. Материалы и макеты UMO лежат в `brand/umo/`. Компоненты экспортируются по умолчанию, вспомогательный код хранится в отдельных модулях.

Проверки: `pnpm exec tsc --noEmit`, `pnpm build`, `pnpm check`. Для визуального сравнения сначала снимите `pnpm check:baseline` на исходной версии. Пуш в `main` запускает публикацию через GitHub Pages.
