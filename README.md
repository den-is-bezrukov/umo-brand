# Сайт бренда

Сайт с материалами бренда: веб-версия стандартов и редактор материалов для дилеров.

- Стандарты бренда — платформа бренда, коммуникация, логотип, типографика, леттеринг, цвет, фотография, пространства и материалы. Логотипы, иконки, леттеринг и номерные таблички скачиваются со страницы.

Редактор материалов для дилеров, на выходе файлы для печати:

- Бейдж — бейджи сотрудников, вручную или из таблицы.
- Визитка — визитки сотрудников дилерского центра, вручную или из таблицы.
- Ливрея — оклейка демо-автомобиля: борта и заднее стекло, название дилера, слоган и QR-код, файл для плоттера и спецификация.
- Прайс-карта — постер A3 с моделью, комплектацией, ценой и QR-кодом.
- Рамка номера — название дилера на рамке номерного знака.
- Режимник — табличка с часами работы и адресом дилерского центра.
- Памятка — памятка владельца A4 с контактами салона и консультанта, и её шаблон с живым текстом.
- Ценник — ценники на аксессуары, восемь на листе A4.

Прайс-карта, ливрея, рамка номера и режимник хранят настройки в адресе страницы, их можно отправить ссылкой; бейдж, визитка и ценник принимают данные из ссылки при открытии. Бейджи, визитки, ценники и режимник открывают свой скачанный PDF обратно.

## Стек

React 19, Vite 8, Tailwind CSS v4, TypeScript; `pdf-lib` для PDF, `opentype.js` для перевода текста в кривые, `qrcode` для QR, `fflate` для таблиц Excel и архивов, `typograf` для типографики текстов. Бэкенда нет — всё генерируется в браузере.
