# UMO Brand

Сайт с материалами бренда UMO — [umo.autos](https://umo.autos):

- [Стандарты бренда](https://umo.autos/) — веб-версия стандартов бренда UMO: платформа бренда, коммуникация, логотип, типографика, леттеринг, цвет, фотография, пространства и материалы. Логотипы, иконки, леттеринг и номерные таблички скачиваются со страницы.

[Редактор материалов](https://umo.autos/editor) для дилеров, на выходе файлы для печати:

- [Бейдж](https://umo.autos/name-tag) — бейджи сотрудников, вручную или из таблицы.
- [Визитка](https://umo.autos/business-card) — визитки сотрудников дилерского центра, вручную или из таблицы.
- [Ливрея](https://umo.autos/livery) — оклейка демо-автомобиля UMO 8 или UMO 5: борта и заднее стекло, название дилера, слоган и QR-код, файл для плоттера и спецификация.
- [Прайс-карта](https://umo.autos/price-card) — постер A3 с моделью, комплектацией, ценой и QR-кодом.
- [Рамка номера](https://umo.autos/plate-frame) — название дилера на рамке номерного знака.
- [Режимник](https://umo.autos/hours-sign) — табличка с часами работы и адресом дилерского центра.
- [Памятка](https://umo.autos/memo) — памятка владельца A4 с контактами салона и консультанта, и её шаблон с живым текстом.
- [Ценник](https://umo.autos/price-tag) — ценники на аксессуары, восемь на листе A4.

Прайс-карта, ливрея, рамка номера и режимник хранят настройки в адресе страницы, их можно отправить ссылкой; бейдж, визитка и ценник принимают данные из ссылки при открытии. Бейджи, визитки, ценники и режимник открывают свой скачанный PDF обратно.

## Стек

React 19, Vite 8, Tailwind CSS v4, TypeScript; `@react-pdf/renderer` и `pdf-lib` для PDF, `opentype.js` для перевода текста в кривые, `qrcode` для QR, `fflate` для таблиц Excel и архивов, `typograf` для типографики текстов. Бэкенда нет — всё генерируется в браузере.
