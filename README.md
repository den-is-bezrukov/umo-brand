# UMO Brand

Сайт с материалами бренда UMO — [umo.autos](https://umo.autos):

- [Стандарты бренда](https://umo.autos/) — веб-версия гайда из Figma: платформа бренда, логотип, типографика, леттеринг, ключевой образ, пространства и носители. Логотипы, леттеринг и номерные таблички скачиваются прямо со страницы (SVG и PNG).
- [Прайс-карта](https://umo.autos/price-card) — конструктор для автодилера: модель и комплектация, ссылка для QR-кода, цена (и, если нужно, цена в кредит) — живой предпросмотр и печатный PDF формата A3.
- [Ливрея](https://umo.autos/livery) — конструктор оклейки демо-автомобиля дилера для UMO 8 и UMO 5: оба борта и заднее стекло, с QR-кодом или без, с названием дилера и слоганом. Тексты проверяются по размерам и не дают залезть на шов между дверями и ручку; на выходе ZIP с векторным файлом для плоттера и спецификацией с размерами на фото машины.

Оба конструктора хранят настройки в адресе страницы: настроенную карту или ливрею можно отправить ссылкой.

## Стек

React 19, Vite 8, Tailwind CSS v4, TypeScript; `@react-pdf/renderer` и `pdf-lib` для PDF, `opentype.js` для перевода текста в кривые, `qrcode` для QR. Бэкенда нет — всё генерируется в браузере.
